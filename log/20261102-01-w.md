## Answers to 20261102-01-a

1. **nostek_agent**: + `edit_pages`, `delete_pages`. No `publish_pages`: a page lands as Pending Review. `delete_pages` only lets the agent Trash its own unpublished page (same as posts), useful for withdrawing; it cannot touch published or other users' pages.
2. **nostek_publisher**: + `edit_pages`, `edit_others_pages`, `edit_published_pages`, `publish_pages`, `read_private_pages`. Still no users, plugins, themes, settings, menus, terms, no deleting.
3. **Existing sites**: caps now live in one list with `NOSTEK_CORE_ROLES_VERSION` = 2 (option `nostek_core_roles_version`). The first page load after the deploy adds the new caps to the roles that already exist. Tested locally from a 0.2.0 site: version 1 to 2, caps added.
4. **nostek_source_id on pages**: registered for `page`; `GET /wp/v2/pages?nostek_source_id=<id>&status=any&context=edit` finds it. `nostek_meta_description` was already on pages.
5. **Menus, read only**: `GET /wp-json/nostek/v1/menus` for users with `edit_posts` (401 without auth). The theme's menus are Navigation blocks in the header and footer, not classic menu locations, so `location` is `header-1`, `footer-1` … `footer-3`. Each menu has a flat `items` list: `id`, `parent` (0 = top), `title`, `url`, `description`, `object` = `{type, slug}` of the page/post/category/topic/product_cat it points to, or `null` (external or not existing yet). `source` = `theme` (from git) or `custom` (edited in the Site Editor). No write route. Format and example in `docs/content-api.md`.
6. **Term hierarchy**: both `/wp/v2/categories` and `/wp/v2/topic` return `parent` (both taxonomies are hierarchical; 0 = top level). Today every term is top level.
7. **Missing terms**: the owner decides. W asked the owner today: (a) Journal sub-sections as child categories under their section, or menu items only; (b) what happens to `classic`, `old-school`, `retro`, `vintage` (W's guess: leftovers from the old demo theme); (c) create Topic `system-administration`. Please post the full list of sub-section names and the section each belongs to (Photography Tips … Collector Interviews, and the Price Index item pages) in your next log, so W can put the exact slugs in `site/pages.json` once the owner decides. Agents still never create terms.

Pages tip: a page's place in the site is `parent` (a page id), not a category. Read the published pages with `GET /pages?status=publish&per_page=100&_fields=id,slug,parent,title,link` before writing, to avoid duplicates.
