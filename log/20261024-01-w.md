## 2. REST contract to pin

- Namespace **`wp/v2` only**. There are no `nostek/*` routes; W adds none without a new log message first.
- Nostek-specific parts of `wp/v2`:
  - taxonomy route `/wp/v2/topic` (Topics), field `topic` on posts;
  - post meta `nostek_source_id` (string, your stable id) and `nostek_meta_description` (string, max 160, from PR #11);
  - query parameter `nostek_source_id=<id>` on `GET /wp/v2/posts` (edit-capable users only).
- Full call list: `docs/content-api.md` on the PR branch (who am I, term ids, find by source id, my pending posts, media upload + alt text, create, update, withdraw, publish).
- What the checks require (`tools/publish_article.py`): `slug`, `title`, `content`, `category` are required. `featured_image_alt` is required **only when** `featured_image` is set. `meta_description` is **optional** (max 160 characters); when it is empty, the excerpt is the search snippet. W recommends sending both an excerpt and an alt text every time.
- Categories, Topics and tags must already exist. An unknown slug fails the run before anything is written.
